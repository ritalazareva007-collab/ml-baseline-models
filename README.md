# Machine Learning Baseline Models 

В данном репозитории реализованы базовые алгоритмы машинного обучения (Baseline Models) для решения задач регрессии и классификации. Проект создан для демонстрации вычисления начальной точки отсчета (baseline), которая необходима для объективной оценки качества более сложных ML-моделей (нейронных сетей, ансамблей и др.). 

Реализация алгоритмов и расчет метрик выполнены с использованием векторных вычислений на базе фреймворка **PyTorch**.

## Технологии
* **Python 3**
* **PyTorch** — тензорные вычисления, реализация алгоритмов и математических метрик.
* **Pandas** — загрузка, обработка данных и заполнение пропусков.
* **Scikit-learn** — стратифицированное разбиение выборок (train/test split).

## Реализованные алгоритмы

1. **Random Prediction Algorithm (Алгоритм случайного предсказания)**
   * *Для классификации:* Выбирает случайный класс из множества уникальных классов обучающей выборки.
   * *Для регрессии:* Выбирает случайное значение целевой переменной из обучающей выборки.
2. **Zero Rule Algorithm (Алгоритм нулевого правила)**
   * *Для классификации:* Детерминированно предсказывает наиболее часто встречающийся класс обучающей выборки.
   * *Для регрессии:* Предсказывает среднее арифметическое целевой переменной обучающей выборки, минимизируя среднеквадратичную ошибку.

## Наборы данных и результаты

### 1. Задача классификации (Heart Disease Dataset)
Цель — предсказать наличие сердечно-сосудистых заболеваний (бинарная классификация). Оценка производится с помощью метрики **Accuracy** (доля правильных ответов).

| Алгоритм | Accuracy | Accuracy (%) |
| :--- | :---: | :---: |
| **Случайное предсказание (Random)** | 0.4880 | 48.8% |
| **Нулевое правило (Zero Rule)** | 0.5020 | 50.2% |

**Вывод:** Алгоритм нулевого правила (50.2%) формирует жесткую нижнюю границу (baseline) для данного набора данных. Любая применяемая в дальнейшем ML-модель должна демонстрировать метрику Accuracy значительно выше этого порога, чтобы доказать свою предсказательную способность.

### 2. Задача регрессии (California Housing Prices)
Цель — предсказать медианную стоимость домов. Оценка производится с помощью метрик абсолютной и среднеквадратичной ошибки (**MAE** и **RMSE**).

| Алгоритм | MAE | RMSE |
| :--- | :---: | :---: |
| **Случайное предсказание (Random)** | 136 153 | 169 705 |
| **Нулевое правило (Zero Rule)** | 90 607 | 114 486 |

**Вывод:** Использование меры центральной тенденции (среднего арифметического) в алгоритме нулевого правила позволило снизить значения ошибок MAE и RMSE в среднем на 33% по сравнению со случайным выбором. Значения MAE = 90 607 и RMSE = 114 486 являются верхней границей допустимой ошибки для будущих моделей регрессии.
