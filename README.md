# Baseline Machine Learning Models 🚀

В данном репозитории реализованы базовые алгоритмы машинного обучения (Baseline Models) для решения задачи регрессии. Проект создан для демонстрации того, как вычисляется начальная точка отсчета (baseline) перед применением более сложных ML-моделей.

В качестве набора данных используется классический датасет **California Housing Prices**.

## 🛠 Технологии
* **Python 3**
* **PyTorch** — реализация алгоритмов и расчет метрик (тензорные вычисления).
* **Pandas** — обработка данных и заполнение пропусков.
* **Scikit-learn** — разбиение выборки (train/test split).

## 🧠 Реализованные алгоритмы
1. **Random Prediction Algorithm (Алгоритм случайного предсказания)** — выбирает случайное значение из множества уникальных значений целевой переменной обучающей выборки.
2. **Zero Rule Algorithm (Алгоритм нулевого правила)** — использует меру центральной тенденции. Для задачи регрессии предсказывает среднее арифметическое целевой переменной обучающей выборки для всех тестовых объектов.

## 📊 Результаты работы

Метрики качества предсказания стоимости жилья (вычислены на тестовой выборке - 20%):

| Алгоритм | MAE (Средняя абсолютная ошибка) | RMSE (Корень из среднеквадратичной ошибки) |
| :--- | :---: | :---: |
| **Случайное предсказание (Random)** | 136153 | 169705 |
| **Нулевое правило (Zero Rule)** | 90607 | 114486 |

**Вывод:** 
Алгоритм нулевого правила прогнозирует данные точнее, чем алгоритм случайного предсказания. Использование меры центральной тенденции (среднего значения) позволило снизить значения ошибок MAE и RMSE в среднем на **33%** по сравнению со случайным выбором. Это доказывает, что Zero Rule является более эффективным базовым алгоритмом для оценки будущих, более сложных моделей машинного обучения.
